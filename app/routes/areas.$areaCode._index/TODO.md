# TODO

1. リスト表示

ユーザーが選択した 都道府県内の市区町村をすべて表示する。

件数は最大190件程度、平均30件程度。

スクロールで探すのが基本の利用スタイル。

2. 探しやすさの工夫

あかさたな行ごとのセクション見出しを配置する。

例：「あ行」「か行」…といった区切りでまとめる。

スクロール中もセクション見出しが見えるようにしたい（インデックス感覚）。

3. ジャンプUI（モバイル中心）

iOSの連絡先アプリのように、画面右側に縦並びのインデックスバーを設ける。

ユーザーがインデックスをタップ、あるいはドラッグすると、対応する「あ行」「か行」などのセクションに一気に移動できる。

4. デスクトップでの補助UI

右側のインデックスバーはモバイル中心とし、デスクトップでは別の補助手段を用意する。

具体的には、セクション見出しをクリックするとモーダルが開き、あかさたなの一覧が表示される。

モーダルから任意の行を選択すると、その行の位置にジャンプできる。

まとめ

基本構造：都道府県内の市区町村を全件リスト表示

補助UI：

モバイル → 右側インデックスバー（iOS連絡先風、タップやドラッグで移動）

デスクトップ → 見出しクリック → モーダルで一覧選択 → ジャンプ
