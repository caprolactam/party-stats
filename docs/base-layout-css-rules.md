# BaseLayout CSSルール仕様書

## 概要

`BaseLayout`コンポーネントは、サイドバーとメインコンテンツエリアを持つレスポンシブレイアウトを提供します。画面幅に応じて適応的にレイアウトが変化し、大画面では中央寄せで表示されます。

## レイアウト構造

```text
┌─────────────────────────────────────────────┐
│                ブラウザ画面                  │
│  ┌─────────┐ ┌─────────────────────────┐   │
│  │サイドバー│ │    メインコンテンツ      │   │
│  │  (固定) │ │       (可変)           │   │
│  └─────────┘ └─────────────────────────┘   │
└─────────────────────────────────────────────┘
```

## CSS変数とブレークポイント

### 基本変数

```css
--space-base: 1rem (≥768px: 1.5rem)  /* 基本スペーシング単位 */
--sidebar-width: 288px                /* サイドバー固定幅 */
--max-screen-width: 1080px           /* レイアウト最大幅 */
--header-height: 56px                /* ヘッダー高さ */
```

### ブレークポイント

```css
--breakpoint-sm: 375px   /* スマートフォン */
--breakpoint-md: 768px   /* タブレット */
--breakpoint-lg: 960px   /* デスクトップ（サイドバー表示開始） */
--breakpoint-xl: 1152px  /* 大画面デスクトップ */
```

## レスポンシブ動作

### 1. モバイル・タブレット (< 960px)

- **サイドバー**: 非表示 (`hidden`)
- **メインコンテンツ**: 全幅使用、左右パディング `--space-base`

```text
┌─────────────────────────────────┐
│     メインコンテンツ（全幅）      │
│  padding: 0 var(--space-base)  │
└─────────────────────────────────┘
```

### 2. デスクトップ (960px ≤ 画面幅 < 1152px)

- **サイドバー**: 表示 (`lg:flex`)、固定幅288px
- **メインコンテンツ**: 左パディング = サイドバー幅 + `--space-base`

```text
┌────────┐┌─────────────────────────┐
│サイドバー││    メインコンテンツ      │
│ 288px  ││ padding-left: 312px    │
│        ││ padding-right: 24px    │
└────────┘└─────────────────────────┘
```

### 3. 大画面デスクトップ (≥ 1152px)

- **中央寄せ**: 全体が`--max-screen-width`(1080px)で中央配置
- **サイドバー**: 中央寄せエリアの左側に配置
- **メインコンテンツ**: 中央寄せエリアの右側、幅768px

```text
┌─────┐┌────────┐┌─────────────┐┌─────┐
│余白 ││サイドバー││メインコンテンツ││余白 │
│     ││ 288px  ││   768px    ││     │
└─────┘└────────┘└─────────────┘└─────┘
       ← 1080px (max-screen-width) →
```

## 詳細なCSS計算式

### サイドバー (aside要素)

#### lg ブレークポイント (960px〜1151px)

```css
width: var(--sidebar-width) /* 288px */
position: fixed
left: 0
```

#### xl ブレークポイント (≥1152px)

```css
width: calc(
  (100% - (var(--max-screen-width) - var(--double-space))) / 2 
  + var(--sidebar-width) 
  - var(--space-base)
)
padding-left: max(
  var(--space-base), 
  calc((100% - var(--max-screen-width)) / 2)
)
```

### メインコンテンツ (div要素)

#### 基本スタイル (全ブレークポイント)

```css
padding: 0 var(--space-base)
```

#### メインコンテンツ lg ブレークポイント (960px〜1151px)

```css
padding-left: calc(var(--space-base) + var(--sidebar-width))
/* 24px + 288px = 312px */
```

#### メインコンテンツ xl ブレークポイント (≥1152px)

```css
padding-right: max(
  var(--space-base), 
  calc((100% - var(--max-screen-width)) / 2)
)
padding-left: calc(
  (100% - var(--max-screen-width)) / 2 
  + var(--sidebar-width) 
  + var(--space-base)
)
```

## 幅の計算結果

### 目標仕様

- **メインコンテンツ幅（パディング除く）**: 768px
- **全体最大幅**: 1080px
- **サイドバー幅**: 288px

### 計算検証

```text
全体幅 = サイドバー幅 + メインコンテンツ左パディング + メインコンテンツ幅 + 右パディング
1080px = 288px + 24px + 768px + 0px ✓

※ 中央寄せ時は左パディングにサイドバー幅が含まれるため、
実際の計算は: 288px + 24px + 768px = 1080px
```

## 制約条件

### 1. ブレークポイントの関係性

```text
--breakpoint-lg ≤ --max-screen-width ≤ --breakpoint-xl
960px ≤ 1080px ≤ 1152px ✓
```

### 2. 最小画面幅での使用可能幅

```text
960px画面でのメインコンテンツ幅 = 960px - 288px - 48px = 624px
十分な幅が確保されている ✓
```

### 3. 設定可能な範囲

- **--breakpoint-lg**: 620px〜1080px（推奨: 768px〜1080px）
- **--max-screen-width**: 任意（メインコンテンツ幅の要件に応じて）
- **--sidebar-width**: 任意（ただし画面幅との兼ね合いを考慮）

## 設計思想

1. **プログレッシブエンハンスメント**: モバイルファーストで、画面幅に応じて機能を追加
2. **柔軟な中央寄せ**: 大画面では読みやすさを重視した幅制限
3. **一貫したスペーシング**: `--space-base`を基準とした統一的な余白設計
4. **アクセシビリティ**: 十分なコンテンツ幅を全ブレークポイントで確保

## 注意点

- CSS変数の変更時は、全ブレークポイントでの表示確認が必要
- サイドバーは固定配置のため、z-indexの管理に注意
- `--space-base`の変更は全体のスペーシングに影響するため慎重に行う
